# Clínica Solmar — redesign demo

A complete mobile-first redesign of the fictional Clínica Solmar dental clinic website.

## Files
- `index.html` — complete page structure and content
- `styles.css` — responsive visual system and layouts
- `main.js` — mobile navigation, English/Spanish toggle, cookie notice, scroll reveals and demo booking handoff

## Preview
Open `index.html` in a browser. The photographic images and Google Fonts are loaded from external services, so an internet connection is required for those assets.

## Before using with a real business
This is a portfolio concept. Replace the fictional clinic's address, phone/WhatsApp number, staff profiles, treatment details, imagery, prices, claims and any other placeholder content with verified client-approved information. The booking form currently opens WhatsApp using a demonstration number (`34600000000`).
